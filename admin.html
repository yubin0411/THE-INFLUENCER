멤버 · 방송 채널

멤버마다 유튜브 · SOOP · 인스타그램 · 프로필 · 공약 · 대표 시그를 넣을 수 있습니다. [편집]을 누르면 언제든 고칠 수 있어요.
연결한 유튜브 채널은 라이브 · 게시글 · Shorts 에, SOOP 방송국은 라이브에 올라가고, 두 곳 방송 시간이 합쳐져 방송 시간 순위에 들어갑니다.

방송 기록 · 월별 방송 시간

유튜브 라이브와 SOOP 방송을 자동으로 기록합니다. 달 · 날짜는 한국 시간 기준이고, 자정을 넘긴 방송은 날짜별로 나눠 셉니다. 멤버를 누르면 방송 목록이 나옵니다.

시그 · 레슨 영상

구글 시트 자동 반영

시그 시트 주소를 넣어 두면 5분마다 시트를 확인해서 바뀐 내용을 자동으로 반영합니다. 바로 반영하려면 [지금 가져오기]를 누르세요.
시트 공유가 "링크가 있는 모든 사용자 → 뷰어"여야 하고, 첫 번째 탭을 읽습니다. 칸 규칙은 아래 엑셀 업로드와 같습니다.

엑셀로 한 번에 올리기

양식 칸: 분류 · 시그 이름 · 시그단가(개) · 유튜브 레퍼런스1 · 2 · 3 · 레슨 영상 (레퍼런스 칸은 몇 개든 모두 읽음, "제외" 칸에 x 를 넣으면 숨김) — 구글 시트에서 파일 → 다운로드 → Microsoft Excel(.xlsx)로 받은 파일을 그대로 올리면 됩니다.
이름이 같은 시그는 내용이 바뀌고, 새 이름은 추가됩니다. 제외 칸에 x 가 있으면 사이트에서 숨겨집니다. 레슨 영상 칸의 유튜브·드라이브 링크는 바로 등록되고, 파일 이름(○○.mp4)은 "파일 대기"로 만들어지니 아래 목록에서 영상 파일을 올려 주세요.
